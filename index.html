⚠️ Conversion automatique bloquée

Facebook n'a pas permis au serveur d'identifier automatiquement le profil.

Pour utiliser le convertisseur, Facebook doit s'ouvrir dans votre navigateur.

🤖 Android

1. Ouvrez les Paramètres du téléphone.

2. Allez dans Applications → Facebook.

3. Ouvrez Ouvrir par défaut ou Définir par défaut.

4. Désactivez Ouvrir les liens compatibles ou Ouvrir les liens pris en charge.

⚠️ Si plusieurs applications ou comptes Facebook apparaissent sur votre téléphone, faites cette manipulation pour chaque application Facebook concernée.

🍎 iPhone / iPad

Sur iPhone, iOS ne propose pas le même réglage qu'Android permettant de désactiver définitivement tous les liens associés à l'application Facebook.

Ouvrez le lien dans Safari.

Si nécessaire, effectuez un appui prolongé sur le lien puis choisissez Ouvrir dans un nouvel onglet lorsque cette option est proposée.

Revenez ensuite sur le convertisseur.

Une fois sur Facebook Web, si vous récupérez le véritable lien du profil, revenez ici et collez-le ci-dessous.

🔒 Aucun mot de passe ni cookie Facebook n'est demandé ou enregistré.
